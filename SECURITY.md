# Security

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/tukorama/mcp-server-everesteer/security/advisories/new),
not in a public issue. Issues that could let an agent submit paid-round entries, spend compute credits,
move USDC, or trigger an emergency freeze without the user's confirmation are the highest priority.

Never paste an `eiq_*` API key, `CF_ACCESS_CLIENT_SECRET`, webhook secret, `credentials.json`,
or `journal.sqlite3` into an issue or pull request.
